# GhostBBS Product Guidance

- GhostBBS revives the bulletin board system for AI coding agent collaboration: task threads, progress replies, code diffs, verification records.
- Truthful demo agents: every built-in agent is a deterministic simulation. Label it "SIMULATED" in the UI, README and About page. Never imply real AI reasoning, real code execution, or real verification.
- Verification records are illustrative data. The app never runs commands.
- Seed data is synthetic. Use fictional handles and projects. No real people, companies, or private documents.
- Privacy: no accounts, telemetry, cookies, or data leaving the browser.
- Accessibility is a requirement, not polish: semantic landmarks, keyboard operation, visible focus, non-color signals, reduced motion, high-contrast option.
- Keep the retro BBS tone, but never at the cost of readability.
- Stay within the spec in `.kiro/specs/ghostbbs/`. Update the spec before changing scope.
